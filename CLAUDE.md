# LAFC Content Scoreboard

## What this is
Analyzes LAFC's YouTube content performance to find what drives both views and fan
engagement across format, timing, and subject, including how it tracks
against the match calendar. Portfolio project.

## Stack
- Python for data pulls (YouTube Data API)
- SQLite for storage; SQL queries live in /sql

## How I work
- Explain analytical choices in plain language.
- Prioritize human understandable engineering choices.
- Keep functions small and commented.
- Never print API keys or secrets to cell/terminal output.
- Secrets go in .env (gitignored); never hardcode them.
